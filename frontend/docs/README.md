# Historical prototype documents

Files in this directory were produced for the designer-driven frontend prototype. They are retained as history and, for Floema materials, as visual reference. They are not an executable plan for the current product.

In particular, the marketplace, purchase-flow, taxonomy and real-catalog documents prescribe static export, mock/localStorage data, fake payments, local cart/provider snapshots or no backend. Those instructions are superseded by [../../docs/README.md](../../docs/README.md). New agents must not implement them.

For current work use the root documentation. If a useful visual idea conflicts with product or architecture, product/architecture wins.
