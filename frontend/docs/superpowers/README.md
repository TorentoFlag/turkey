# Архив спецификаций дизайн-прототипа

Эти документы сохранены как история решения и, частично, как визуальный референс. Они **не являются** действующими инструкциями для разработки.

Не исполняйте требования о static export/GitHub Pages, mock или `localStorage` данных, локальной корзине, форме карты, фиктивной оплате, фиксированной taxonomy, supplier snapshots или отсутствии backend/auth/payment. Актуальный источник истины находится в корневом [docs/README.md](../../../docs/README.md) и [AGENTS.md](../../../AGENTS.md).

Floema-документы допустимо читать только для визуальных принципов. При противоречии всегда приоритетны продуктовые правила и архитектура.
